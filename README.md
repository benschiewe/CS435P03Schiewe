
# Recursive Descent Parser w/ ANTLR




## Usage/Examples

To build the project (run ANTLR code generation and Java compilation), run

```bash
./build.bat
```


## Running Tests

To run tests, run the following command

```bash
  ./test.bat
```

This will parse ```/tests/sample-[1-5].txt``` and generate output files in the same directory

You can also run the following commands for individual tests

```bash
  java CS435P03Schiewe tests/sample[*].txt
  grun P03Schiewe program -gui tests/sample[*].txt
```
